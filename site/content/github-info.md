## Latest GitHub Updates

### GitHub Copilot & AI
- **Copilot Workspace (Preview):** Plan, build, test, and run code from natural language prompts. [GitHub Blog, Apr 29, 2024](https://github.blog/2024-04-29-introducing-github-copilot-workspace-preview/)
- **Copilot Chat:** Now generally available for all Copilot users. Get contextual code help, code generation, and debugging in your IDE. [GitHub Blog, Feb 27, 2024](https://github.blog/2024-02-27-github-copilot-chat-is-now-generally-available/)

- **Suggest Multiple Code Changes:** Reviewers can now suggest multiple code changes in a single PR comment. [Changelog, May 2, 2024](https://github.blog/changelog/2024-05-02-suggest-multiple-code-changes-in-a-single-pull-request-comment/)
- **Project Management:** GitHub Projects supports custom fields, better filtering, and automation. [Changelog, Mar 21, 2024](https://github.blog/changelog/2024-03-21-github-projects-custom-fields-and-automation/)

### Security
- **Secret Scanning & Push Protection:** Expanded to more repos and secret types. [Changelog, Apr 18, 2024](https://github.blog/changelog/2024-04-18-secret-scanning-and-push-protection-for-more-repositories/)
