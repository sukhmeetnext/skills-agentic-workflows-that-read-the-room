### Awesome Copilot Workflows

- **Code Generation from Comments:** Write a comment, let Copilot generate the code. [Source](https://awesome-copilot.github.com/workflows/#code-generation)
- **Refactoring:** Select code, prompt Copilot to refactor for readability or performance. [Source](https://awesome-copilot.github.com/workflows/#refactoring)
- **Writing Unit Tests:** Comment 'Unit test for above function' and Copilot generates the test. [Source](https://awesome-copilot.github.com/workflows/#testing)
- **Generating Documentation:** Add a docstring/comment, Copilot completes it. [Source](https://awesome-copilot.github.com/workflows/#documentation)
- **Code Review Assistance:** Ask Copilot to explain or review code. [Source](https://awesome-copilot.github.com/workflows/#code-review)
- **Language Conversion:** Comment 'Convert to JavaScript' (or other language), Copilot translates. [Source](https://awesome-copilot.github.com/workflows/#language-conversion)
- **Filling in Boilerplate:** Start a class or handler, Copilot completes the pattern. [Source](https://awesome-copilot.github.com/workflows/#boilerplate)
