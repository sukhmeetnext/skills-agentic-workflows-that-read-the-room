## Latest GitHub Updates

- **[2026-07-30] GitHub Models is now retired** ([Changelog](https://github.blog/changelog/2026-07-30-github-models-is-now-retired))
  - The GitHub Models playground, model catalog, and inference API are no longer available. For AI model access, use Microsoft Foundry or GitHub Copilot. ([source: GitHub Changelog])

- **[2026-07-30] Reference same-repository actions with self-repository syntax** ([Changelog](https://github.blog/changelog/2026-07-30-reference-same-repository-actions-with-self-repository-syntax))
  - You can now use `$/` in GitHub Actions to reference actions and workflows in the same repo, improving maintainability and SHA pinning. ([source: GitHub Changelog])

- **[2026-07-30] Stacked sessions and pull requests in the GitHub Copilot app** ([Blog](https://github.blog/ai-and-ml/github-copilot/stacked-sessions-and-pull-requests-in-the-github-copilot-app/))
  - The Copilot app now supports stacked sessions and PRs, making it easier to modernize codebases and manage related changes. ([source: GitHub Blog])

- For more Copilot workflow ideas, see [Awesome Copilot Workflows](https://awesome-copilot.github.com/workflows/). ([source: Awesome Copilot workflows])
